# style-review

writing-kitのguidelineと照合して、逸脱箇所を指摘し、修正案を出す。共通ルールは`common_guideline.md`、散文の用途別の書き方は`style_article.md`・`style_academic.md`・`style_memo.md`、箇条書きの文書の形式は`style_bullet.md`が定める。

## 前提

- 本skillのディレクトリを基準にした次のパスのguidelineファイルを必ず読み込む：
    - 対象が何であれ → `../../guidelines/common_guideline.md`
    - 散文の節が対象 → 加えて、対象の用途に応じた `../../guidelines/style_article.md`（記事）または `../../guidelines/style_academic.md`（論文のような論説文）または `../../guidelines/style_memo.md`（自分用のメモ）。用途は文末（です・ます調／だ・である調）と内容から判別し、判別できない場合（短い断片など）はユーザーに質問する
    - 箇条書きの節が対象 → 加えて `../../guidelines/style_bullet.md`
    - 散文の節と箇条書きの節が混在している場合（箇条書きの文書を散文に書き直している途中など）は、両方読み込んで節ごとに照合する

## 進め方

1. **対象を判定する**。ユーザーから渡された文書の形式を、節ごとに判定する。節の地の文が散文なら散文の節、箇条書きなら箇条書きの節とする。導入の散文のあとに列挙の箇条書きが続く節は、散文の節として扱う（その箇条書きは用途別guidelineの「本文中の箇条書き」で見る）。散文の節がある場合は用途も判別する。判別不能な場合は質問する

2. **guidelineを読み込む**。判定結果に応じて対応するguidelineを読む

3. **項目ごとに照合する**。guidelineの各ルールに対して、対象文章のどこが合致・逸脱しているかをチェックする。

    共通（箇条書き・散文の両方で見る。common_guidelineに対応）：
    - 認識の帰属（意見の一般論へのすり替え、定説・研究の帰結・自分の推論の書き分け、儀式的なエクスキューズの禁止、実質的な留保）
    - 命題・概念の扱い（空虚な形容・流行語の禁止、見立てのラベル化禁止、自作区分のマトリクス演出禁止）
    - 修辞（語りかけ・問いかけ・見得を切る演出・予告総括の型の禁止、先回り訂正）
    - 論の進め方（セクション間のつなぎの位置、既出概念の再参照、形式的まとめの禁止）
    - 読者の前提（文書の外の文脈に頼った主語・対象の省略、定義のない略称や仮の名前）
    - 引用・出典（Author (Year)形式、参考文献の書式、書名『』、URL表記）
    - 表記（漢字/かなの使い分け、英語術語、カタカナ、「」/ "" /『』の使い分け、中黒、括弧、句読点、数字）
    - Markdown（見出しの中身、太字・イタリック・絵文字・記号の禁止、表を使ってよい場面）

    散文の節はさらに（記事・論文の場合。用途別guidelineに対応）：
    - 文体（文末の基本形、一人称の扱い）
    - 語り口（口語的なゆるさの扱い、ヘッジの表現形、提案の抑制、文末表現の混在）
    - 段落の作り方（3〜6文、ぶつ切りの禁止）
    - つなぎ・参照の言い回し（接続語、前内容への参照、ロードマップ文）
    - 本文中の箇条書き（だ・である調/体言止め、句点の扱い、箇条書きと散文の使い分け、箇条書きの形式）

    メモの場合はさらに（style_memoに対応）：
    - 文体・語り口（だ・である調と体言止め、一人称なし、行末に句点を付けないこと、確かめたことと推測の書き分け、話し言葉寄りの言い回しの許容、1文の情報量）
    - 進め方（その場で書き進める視点、冒頭で何をするかと始める時点での見立てを示す、実際に進めた順に書く、先回りした説明の禁止、その場の注記の書き方、「：」の使いどころ、どこまで扱うかの判断、寄り道から戻ることの明示）
    - 素材・出典・地の文（出典の置き方、参考文献の節を置かない、段落を作らない、箇条書きの使いどころ）

    箇条書きの節はさらに（style_bulletに対応）：
    - 基本形式（1行1命題、複数トピックの同居禁止、だ・である調/体言止め、句点なし、用語導入形式、補足の子bullet化、執筆メタ記述の禁止）
    - 認識の帰属（語尾または構造での標示）
    - 並び順とまとまり（論証順、論理関係を示す語、水平線による区切り）
    - ネスト（子bulletの役割）
    - 文献・出典の書き方

4. **レポートする**。逸脱の重要度が高いもの・件数が多いものから順に整理して出す。各指摘は以下を含める：
    - 逸脱箇所（原文引用または行番号）
    - どのルールに反しているか（guidelineの該当項目）
    - 修正案

## 注意

- guidelineで明示的に許容されているもの（漢字/かなの文脈依存的な変化、実質的な情報を持つ留保、文献由来の隠喩術語など）は逸脱として扱わない
- 逸脱の指摘は「機械的な違反検出」ではなく、なぜそのルールがあるかを踏まえた文脈的判断で行う。ルールと衝突するように見えても文脈上正当な選択なら指摘しない
- 用途の判別を誤ったまま照合しない。記事にstyle_academicを当てる、メモにstyle_academicを当てるなどすると指摘が全て誤りになるため、判別に少しでも迷いがあればユーザーに確認する
- 全ての逸脱を一度に出すと大量になる場合は、優先度の高い5〜10件程度から先に提示し、残りは分類ごとにまとめて追加する形にする
- 修正案は複数の選択肢を提示できる場合は提示する（例：「〜てみる」を「〜てみる」のままにするか、「〜しに行く」に置き換えるか等）
